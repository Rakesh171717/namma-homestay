# Namma Homestay

Android app for small rural homestay hosts and travelers. It supports host profiles, daily menu updates, inquiry chat, local guide spots, calendar availability, and Firebase Authentication with Firestore-backed data.

## Setup

1. Add your Firebase `google-services.json` to `app/`.
2. Enable Email/Password Authentication in Firebase Console.
3. Create a Firestore database.
4. Open the project in Android Studio and run the `app` configuration.

Firebase setup details are in `FIREBASE_SETUP.md`.
